# ملاحظات المالك — مواضيع نرجع لها

المبنى جاهز لكن **ما يرسل لين تُضاف أسرار Resend** (`RESEND_API_KEY`، `EMAIL_FROM` بنطاق موثّق، و`SITE_URL`). التفاصيل: `docs/SUPERVISOR_EMAIL.md`.
باقي: تجربة إيميل حقيقي، وبند الخصوصية بـ `src/lib/legal.ts`، وفكرة إيميل أسبوعي بملخص التقدم.

## 2. ملاحظة الدكتورة على «وكيل البحث العلمي» (2026-10-01)
عرضتُ الأداة على الدكتورة فقالت (بحسب نقل المالك): «هذا تاخذه just for fun، يعني فيه طريقة بالبحث يسوّونها» — ما اتضح المقصود بالضبط.
**الفهم المرجّح:** الأداة تنفع للاستكشاف وتوليد أفكار، لكن مراجعة الأدبيات الرسمية لها منهج موثّق (بحث منهجي: قواعد بيانات، كلمات وعمليات بوليانية، معايير قبول/استبعاد، مخطط PRISMA، تقييم جودة الدراسات) والنتيجة لازم تكون قابلة للتتبّع وإعادة التنفيذ.
**اللي عندنا:** تبويب «خطة البحث» (`SearchStrategy.tsx`) يبني PICO وكلمات مفتاحية وجمل بحث لـ PubMed/CINAHL/Scopus ومعايير قبول/استبعاد.
**ناقص (لو تأكد إنه المقصود):** سجل بحث موثّق (قاعدة البيانات، تاريخ البحث، الجملة المستخدمة، عدد النتائج)، مخطط PRISMA تلقائي (تعريف/فرز/اشتمال)، تقييم جودة (JBI/CASP) لكل دراسة.
**قبل البناء:** نسأل الدكتورة سؤال محدد (انظر المحادثة).

## 3. «مساعد المراجعة المنهجية» — خطة لنرجع لها (حُفظ 2026-10-01)
**السياق:** الدكتورة قالت عن وكيل البحث «just for fun» وإن فيه طريقة بالبحث. المرجّح: EBP (Evidence-Based Practice). **لسا ما تأكدنا — لازم نسألها قبل البناء**: «نصنّف الدراسات حسب مستوى الدليل ونقيّم جودتها ونوثّق البحث، هذا المطلوب؟».

**الفكرة:** الذكاء الاصطناعي يسوي أغلب الشغل، والإنسان يوافق على كل قرار (الأمانة الأكاديمية + أخطاء الذكاء الاصطناعي).

| الخطوة | الذكاء الاصطناعي | الإنسان |
|---|---|---|
| السؤال | يصيغ سؤال البحث (PICO) | يوافق/يعدّل |
| الاستراتيجية | كلمات وجمل لكل قاعدة | يراجع |
| تنفيذ البحث | يبحث ويحفظ سجل (قاعدة، تاريخ، جملة، عدد) | — |
| الفرز | يقترح قبول/استبعاد مع السبب | يوافق على كل قرار |
| تقييم الجودة | يعبّي قائمة مبدئية | يراجع (يفضّل بنص كامل) |
| جدول الأدلة | يستخرج البيانات ويحدد مستوى الدليل | يصحح |
| الكتابة | مخطط PRISMA تلقائي + مسودة تلخيص | يعتمد |

**مراحل البناء المقترحة:**
1. مستوى الدليل بمكتبة الأدلة.
2. سجل البحث (جدول جديد).
3. الفرز بمساعدة الذكاء الاصطناعي مع موافقة الفريق + أرقام PRISMA.
4. التقييم وجدول الأدلة + تصدير Word.
5. مخطط PRISMA ومسودة التلخيص.

**قيود لازم نتذكرها:**
- نبحث فقط بـ PubMed وOpenAlex — ما نقول إننا بحثنا بـ CINAHL/Scopus (ما عندنا وصول). السجل يذكر القواعد المستخدمة فعلًا.
- أدوات JBI/CASP عليها حقوق: نكتب «تقييم مبدئي» بصياغتنا ونذكر الأداة الرسمية.
- ضمن باقة الذكاء الاصطناعي (تكلفة استخدام).
- شغل أسابيع، وبعضه يحتاج جداول بقاعدة البيانات.
