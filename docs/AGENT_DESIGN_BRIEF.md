## مطلوب من المصمم
1. بطاقة الوضع: ترتيب بصري أوضح (حلقة تقدم بدل شريط؟ أيقونات؟)، ٣ حالات: كل شي تمام / فيه متأخر / بدون مرحلة.
2. الردود السريعة: شكل الزر، حالة الضغط، ظهور متدرّج (stagger) خفيف.
3. حالة «يشتغل»: حركة الكرة + تدرّج الخطوات (بدون مبالغة).
4. بطاقة الموافقة: معاينة «قبل/بعد» للهدف والأسئلة (حالياً نص واحد) + حالة تم/تراجع.
5. شارة «حسب قراركم السابق» لما يستخدم الوكيل ذاكرة المشروع (لسا ما انبنت — تحتاج تصميم أولاً).
6. الجوال أولاً: لمس ≥ ٤٤px، RTL، نص ١٥px كحد أدنى بالمحادثة.

## قواعد
- لا إيموجي ولا علامات تعجب بنصوص الوكيل (أسلوب احترافي).
- أي نص جديد يمر بـ `tr()` ليدعم الإنجليزي.
- لا تغيّر أسماء الخصائص (props) بدون إبلاغ المطوّر.
