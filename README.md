# NURSYNC

منصة إدارة أبحاث التخرج لفرق طلاب التمريض (٥ طلاب لكل فريق).

## الحالة الحالية

الواجهة مبنية بالكامل، وفيها **دعم Supabase حقيقي جاهز** (تسجيل دخول
بالبريد وكلمة المرور، أدوار قائد/عضو، جدول مهام متزامن لحظيًا). طالما
ما ضفت مفاتيح Supabase، يشتغل الموقع تلقائيًا بوضع تجريبي (بيانات وهمية
وتسجيل دخول بدون كلمة مرور) — راجع قسم "ربط Supabase" تحت.

## التقنيات

- **React 19 + TypeScript** عبر **Vite**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **React Router v7** (`HashRouter`) للتنقل بين الصفحات
- **@supabase/supabase-js** للمصادقة وقاعدة البيانات (اختياري، يُفعّل تلقائيًا)
- **lucide-react** للأيقونات
- خط **IBM Plex Sans Arabic / Tajawal** عبر Google Fonts
- تصميم **RTL** بالكامل (`dir="rtl"`) مع شريط جانبي على اليمين، وألوان
  دافئة (تيل + أزرق فاتح + أصفر دافئ) على خلفية كريمية بأسلوب بطاقات
  Bento

## الصفحات

- **الرئيسية** — ترحيب، عداد أيام التسليم وشريط التقدم، مؤشرات سريعة،
  تقويم شهري، أولويات اليوم، تقدم البحث بـ 7 مراحل رئيسية
- **دليل الطالب** — شرح لكل صفحة ووين تروح لها، وخطوات إسناد/إنجاز المهام
- **خطة البحث** — 12 مرحلة تفصيلية بحالتها وتقدمها ومسؤولها
- **المهام** — فلترة حسب الحالة، وإسناد مهام جديدة (لقائدة الفريق فقط) —
  متصلة بجدول Supabase حقيقي مع تحديث لحظي عند تفعيله
- **الفريق** — بطاقات الأعضاء الخمسة مع نسبة إنجاز كل عضو
- **الجدول الزمني** — عرض Gantt مبسّط لمراحل البحث الـ 12
- **الميدان** — خريطة مواقع جمع البيانات (الرياض، جدة، الدمام، المدينة، مكة)
- **المراجع** — قائمة المصادر العلمية مع تصنيفها ووسومها
- **الملفات** — ملفات الفريق مصنّفة حسب المجلد
- **التقويم** — تقويم شهري كامل مع أحداث اليوم المحدد

## ربط Supabase (تسجيل دخول حقيقي + مزامنة المهام)

1. أنشئ مشروع مجاني على [supabase.com](https://supabase.com).
2. من **SQL Editor** داخل مشروعك، الصق محتوى ملف
   [`supabase/schema.sql`](./supabase/schema.sql) كامل واضغط **Run**.
   هذا ينشئ جدولي `profiles` و `tasks` مع صلاحيات (RLS) تمنع أي شخص غير
   قائد الفريق من إسناد مهام جديدة، ويفعّل التحديث اللحظي (Realtime).
3. انسخ `.env.example` إلى ملف جديد اسمه `.env`، وعبّي القيمتين من
   **Project Settings → API**:
   ```
   VITE_SUPABASE_URL=...
   VITE_SUPABASE_ANON_KEY=...
   ```
4. شغّل `npm run dev` من جديد — الموقع بيكتشف تلقائيًا وجود Supabase
   ويحوّل صفحة الدخول إلى نموذج بريد إلكتروني/كلمة مرور حقيقي.
5. خلّي كل عضو من الأعضاء الخمسة يسوي "إنشاء حساب" بنفسه من صفحة الدخول.
6. بعد ما تسجّل قائدة/قائد الفريق حسابها، ارجع لـ SQL Editor وشغّل
   (بعد تغيير البريد):
   ```sql
   update public.profiles set role = 'leader' where email = 'leader@example.com';
   ```

بعد هذه الخطوات: تسجيل الدخول وصفحة **المهام** يصيرون حقيقيين ومتزامنين
بين كل أعضاء الفريق فورًا. باقي الصفحات (خطة البحث، الميدان، المراجع،
الملفات...) لسا على بيانات وهمية — نفس نمط ربط جدول `tasks` ينطبق عليها
لاحقًا.

## هيكل البيانات

- الأنواع (Types) في `src/data/types.ts`
- البيانات الوهمية في `src/data/mockData.ts`
- عميل Supabase في `src/lib/supabaseClient.ts`
- مخطط قاعدة البيانات في `supabase/schema.sql`
- منطق المصادقة (وضع Supabase + الوضع التجريبي) في `src/context/AuthContext.tsx`
- خطافات (Hooks) البيانات الحقيقية في `src/hooks/useTeamRoster.ts` و
  `src/hooks/useTasksData.ts`
