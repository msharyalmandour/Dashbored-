# إيميلات المشرفة — التشغيل

**الفكرة:** المشرفة (بدون حساب) تفعّل الإشعارات بنفسها من رابطها: تكتب إيميلها ← يوصلها إيميل تأكيد ← بعد التأكيد يوصلها
إيميل عند كل رد من الفريق. ما يُرسل شي لأي إيميل قبل ما يؤكده صاحبه (حماية من إساءة الاستخدام).

## المكونات
- جدول `supervisor_email_subscriptions` (RLS مفعّل بدون سياسات؛ يصله فقط الـ Edge Function). الإيميل ما يظهر لأي عميل — الواجهة تشوف نسخة مقنّعة `a***@x.com` فقط عبر `get_supervisor_email_status` و`get_my_supervisor_email_status`.
- دالة Edge: `supabase/functions/supervisor-email` (verify_jwt=false؛ كل إجراء يوثّق نفسه). الإجراءات: `subscribe` · `confirm` · `unsubscribe` · `notify`.
- الواجهة: `SupervisorEmailCard` (صفحة المشرفة)، `SupervisorEmailAction` (`/#/supervisor-email/confirm|unsubscribe/<token>`)، حالة الاشتراك + «إرسال بالإيميل» (mailto) بصفحة الفريق، وإشعار تلقائي بعد رد الفريق بصفحة «ملاحظات المشرف».

## لازم تضبطه قبل ما يشتغل الإرسال (Supabase ← Edge Functions ← Secrets)
| السر | القيمة |
|---|---|
| `RESEND_API_KEY` | مفتاح API من حساب Resend |
| `EMAIL_FROM` | مثل `Wesync <noreply@نطاقكم>` — **النطاق لازم يكون موثّقًا (SPF/DKIM) بـ Resend** وإلا الإيميلات تروح للمزعج أو ترفض |
| `SITE_URL` | اختياري؛ الافتراضي `https://dashbored-sigma.vercel.app` (لازم يطابق عنوان الموقع النهائي) |

بدون `RESEND_API_KEY` و`EMAIL_FROM` الدالة ترجّع `email_not_configured` والواجهة تعرض رسالة ودّية، ويبقى واتساب كبديل.

## الحدود
- طلب اشتراك: ٥ مرات باليوم لكل فريق، وبين الطلب والثاني دقيقة على الأقل.
- إشعار «رد جديد»: مرة كل ١٠ دقائق لكل فريق (ردود كثيرة بسرعة تنجمع بإيميل واحد لاحق).
- نص الرد بالإيميل يُقتطع عند ٤٠٠ حرف، وكل النصوص تُهرَّب (escape) قبل الإدراج بالـHTML.

## خصوصية
الإيميل بيانات شخصية. أضيفوا بند لصفحة الخصوصية (`src/lib/legal.ts`) يذكر: جمع إيميل المشرفة بموافقتها، استخدامه لإشعارات المحادثة فقط، وإمكانية الإيقاف من كل إيميل. (ما عدّلتُ النص القانوني — يحتاج مراجعتكم.)
