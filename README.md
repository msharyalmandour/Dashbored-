# NURSYNC

منصة إدارة أبحاث التخرج لفرق طلاب التمريض (٥ طلاب لكل فريق).

## الحالة الحالية

الواجهة مبنية بالكامل ببيانات وهمية (Mock Data) وتسجيل دخول تجريبي (اختيار
عضو من القائمة بدون كلمة مرور). لا يوجد اتصال حقيقي بقاعدة بيانات بعد.

## التقنيات

- **React 19 + TypeScript** عبر **Vite**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **React Router v7** للتنقل بين الصفحات
- **lucide-react** للأيقونات
- خط **IBM Plex Sans Arabic / Tajawal** عبر Google Fonts
- تصميم **RTL** بالكامل (`dir="rtl"`) مع شريط جانبي على اليمين

## الصفحات

- **الرئيسية** — ترحيب، عداد أيام التسليم وشريط التقدم، مؤشرات سريعة،
  تقويم شهري، أولويات اليوم، تقدم البحث بـ 7 مراحل رئيسية
- **خطة البحث** — 12 مرحلة تفصيلية بحالتها وتقدمها ومسؤولها
- **المهام** — فلترة حسب الحالة، وإسناد مهام جديدة (لقائدة الفريق فقط)
- **الفريق** — بطاقات الأعضاء الخمسة مع نسبة إنجاز كل عضو
- **الجدول الزمني** — عرض Gantt مبسّط لمراحل البحث الـ 12
- **الميدان** — خريطة مواقع جمع البيانات (الرياض، جدة، الدمام، المدينة، مكة)
- **المراجع** — قائمة المصادر العلمية مع تصنيفها ووسومها
- **الملفات** — ملفات الفريق مصنّفة حسب المجلد
- **التقويم** — تقويم شهري كامل مع أحداث اليوم المحدد

## التشغيل محليًا

```bash
npm install
npm run dev
```

## هيكل البيانات الوهمية

كل البيانات التجريبية موجودة في `src/data/mockData.ts` و
`src/data/types.ts`. حالة تسجيل الدخول التجريبي موجودة في
`src/context/AuthContext.tsx`.

## الخطوة القادمة: ربط Supabase

للانتقال إلى بيانات حقيقية متزامنة بين أعضاء الفريق:

1. إنشاء مشروع على [supabase.com](https://supabase.com) (الخطة المجانية).
2. إنشاء الجداول: `teams`, `team_members`, `research_phases`, `tasks`,
   `fieldwork_sites`, `calendar_events`, `references`, `files` — بما
   يعكس الأنواع الموجودة حاليًا في `src/data/types.ts`.
3. تفعيل **Supabase Auth** (بريد إلكتروني/كلمة مرور) واستبدال
   `AuthContext.tsx` الحالي (الذي يعتمد على اختيار مستخدم وهمي) بجلسة
   Supabase حقيقية، مع عمود `role` (`leader` / `member`) وربطه بسياسات
   **Row Level Security** بحيث لا يقدر إلا قائد الفريق على إسناد المهام.
4. استبدال البيانات الوهمية في الصفحات باستعلامات Supabase
   (`supabase-js`) مع الاستماع للتحديثات اللحظية عبر **Realtime** حتى
   تتزامن التغييرات بين كل أعضاء الفريق فورًا.
5. إضافة متغيرات البيئة `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY`.
