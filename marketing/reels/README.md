# ريلز Wesync

## SaaS promo (2026-10-01) — `films/wesync-saas-promo-v2.mp4`
أسلوب منتج SaaS بالهوية الثابتة (Obsidian × Ember): مشكلة ← لقطات حقيقية من الموقع بالثيم الأسود ← خاتمة بالشعار.
بُني بالكامل بدون توليد فيديو: لقطات الموقع (وضع العرض التجريبي، ٣٩٠×٨٤٤ ×٣) + مشهد HTML متحرك يُصوَّر إطارًا بإطار
(Playwright، ٣٠ إطار/ث) + راوي ElevenLabs + موسيقى Higgsfield (sonilo) + مؤثرات sox + ducking ثم تسوية الصوت (-16 LUFS).
النص العربي كله بخط Tajawal من ملف محلي. الراوي ينطق الاسم «ويسنك».

لإعادة الإنتاج: التقاط الشاشات يحتاج بناء الموقع بوضع العرض التجريبي (isSupabaseConfigured=false) — سكربتات الالتقاط والمشهد
عاشت بصندوق Higgsfield فقط (لم تُحفظ بالمستودع).

## Ember Library (قديم، واقعي) — لا نستخدمه: المالك ما أعجبه، ومطلوب أسلوب منتج SaaS.

## SaaS premium (2026-10-01) — النسخة الأفخم
نفس البنية + طبقة فخامة: حبيبات فيلم وفينييت، جزيئات جمر عائمة، عناوين كلمة بكلمة مع blur، جوال ثلاثي الأبعاد مع لمعان،
شرائح زجاجية (chips) بحدود متدرجة، وميض عند كل انتقال، وحلقات وضوء على الشعار. المستضاف: Higgsfield CDN (الرفع لـ Supabase كان بطيئًا).
الصوت: ستيريو. الراوي بسلسلة استوديو (EQ + ضغط + ريفيرب خفيف)، موسيقى cinematic جديدة (sonilo) مع ducking قوي، وتصميم صوتي:
boom عميق، whoosh بطبقتين، ticks زجاجية، shimmer، riser قبل الخاتمة، وstinger وتر. كل سطر راوي يُطبَّع على مستوى موحّد
(التطبيع الآلي يفشل على المقاطع القصيرة <٣ث فكان سطر ٢ أهدأ بـ٩ ديسيبل). الموسيقى تُضبط -14 ديسيبل تحت الراوي.
